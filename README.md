# Servidor SQL & API Backend (Java)

Sistema backend encargado de gestionar la lógica de negocio, procesar peticiones y administrar la base de datos para la aplicación web.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java
* **Base de Datos:**  PostgreSQL
* **Conectividad / Frameworks:**   Spring Boot 
* **Lógica del Sistema:** Gestión de usuarios, almacenamiento estructurado y procesamiento de datos.
